# 🛒 Ishu FreshCart — Grocery App

A full-stack grocery selling application with a premium dark-themed UI.

## Features
- 🏪 24 grocery items across 6 categories
- 🔍 Real-time search
- 🛒 Cart drawer with quantity controls
- 💳 Checkout with order placement
- 📦 Order history
- 🎨 Dark glassmorphism UI with animations

## Tech Stack
- **Backend:** Node.js + Express
- **Frontend:** Vanilla HTML/CSS/JS
- **Data:** In-memory storage

## Run Locally

```bash
npm install
npm start
```

Open **http://localhost:3000**
